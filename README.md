# 自动定投看板

在线地址：https://gilgamesh911.github.io/dca-dashboard-pages/

## 计划与估算

- 支付宝从 2026-10-27 起，017641、019305、019172、019173 各按 ¥10/工作日推算。
- 每笔订单到预计 T+2 工作日且对应净值已公布后，才计入估算份额。节假日和平台实际确认时间可能造成差异。
- 富途从 2026-11-10 起，3195 港元柜台按 HK$1,000/月推算，假设可买零碎份额。
- 默认计划中的每笔都成功；不连接账户、不下单，也不代表真实持仓。
- 红利再投只在公开净值数据出现可识别分红事件时增加份额；截至首次上线时，四只基金从计划开始日尚无识别到的分红。

## 数据与图表

- 页面每 60 秒尝试读取标普500、纳指100及3195报价，失败时显示上次成功数据。报价日期在页面展示。
- GitHub Actions 每天获取四只基金净值、3195历史日线、五个指数日线和欧洲央行汇率，写入 `data/market.json`。
- 收益曲线把四只支付宝基金与富途 3195 合并为「我的自选总收益」一条线，并与标普500、纳指100、恒生、沪深300、日经225 比较。五条指数线均模拟相同投入现金流（¥40/工作日及 HK$1,000/月）；港币资产和投入按对应日期汇率折算人民币。曲线末端及图例显示收益率，只有足够的共同可比日期才显示跑赢数量。收益日历按月份展示计划开始后的每日估算盈亏。QDII 净值按次一工作日可见处理；无可确认收益的日期显示灰色。
- 标普500/纳指100/日经225日线：FRED；恒生指数/沪深300/3195日线：腾讯财经；汇率：欧洲央行；基金净值与标普500即时报价：东方财富；纳指100与3195报价：腾讯财经。公开数据源可能延迟、限流或变更。

本仓库公开计划和行情，不包含个人账户凭据或实际成交记录。暂无经过核实可供个人 OAuth 授权读取蚂蚁财富基金持仓的公开接口，因此没有账户连接功能。

## 基金费用估算

支付宝四只基金的每笔 ¥10 申购按基金类别分别计算。A 类使用用户提供的支付宝优惠申购费率（50 万以下 0.12%、50–100 万 0.08%、100–500 万 0.03%、500 万及以上每笔 ¥1,000）；C 类免申购费。每笔费用按人民币分四舍五入，净申购金额除以当日净值计算份额。无新净值披露的日期沿用上一估值日的累计收益，新确认申购费在下次净值更新时进入收益计算。当前估算仅有买入，没有赎回，所以赎回费不扣除。管理费、托管费与 C 类销售服务费已经在公布的单位净值中反映，不再另扣。申购费及确认份额以支付宝实际订单为准。

四只基金的标准费率以[摩根基金 017641](https://www.cifm.com/fund/017641/)、[019305](https://www.cifm.com/fund/019305/)、[019172](https://www.cifm.com/fund/019172/)、[019173](https://www.cifm.com/fund/019173/)官方页面为依据；A 类优惠费率由用户提供，可能随支付宝活动调整。
