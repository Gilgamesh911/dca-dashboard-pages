# 自动定投看板

公开站点：https://gilgamesh911.github.io/dca-dashboard-pages/

- 支付宝从 2026-10-27 起，四只 QDII 各按 ¥10/工作日自动推算：017641、019305、019172、019173。
- 富途从 2026-11-10 起，3195 港元柜台按 HK$1,000/月自动推算。
- 不连接账户、不下单；“每笔成功”为模拟假设。未拿到对应净值/价格的订单计为待确认现金。
- 页面每 60 秒从东方财富公开行情接口尝试获取 SPX、NDX 与 3195。页面展示行情时间戳；公开接口可能延迟、限流或变更。
- GitHub Actions 每天抓取四只基金的最新公布净值及 3195 历史日线，生成 `data/market.json`。人民币和港币不合并。
- 净值与行情数据来自东方财富非官方公开接口；页面并非券商持仓证明。

本仓库只包含公开计划、程序和公开行情，不包含成交记录或账户凭据。
