## 计划与估算

- 支付宝从 2026-10-27 起，017641、019305、019172、019173 各按 ¥10/工作日推算。
- 每笔订单到预计 T+2 工作日且对应净值已公布后，才计入估算份额。节假日和平台实际确认时间可能造成差异。
- 富途从 2026-11-10 起，3195 港元柜台按 HK$1,000/月推算，假设可买零碎份额。
- 默认计划中的每笔都成功；不连接账户、不下单，也不代表真实持仓。
- 红利再投只在公开净值数据出现可识别分红事件时增加份额；截至首次上线时，四只基金从计划开始日尚无识别到的分红。

## 数据与图表

- 页面每 60 秒尝试读取标普500、纳指100及3195报价，失败时显示上次成功数据。报价日期在页面展示。
- GitHub Actions 每天获取四只基金净值、3195历史日线、五个指数日线和欧洲央行汇率，写入 `data/market.json`。
- 收益曲线让五个热门指数采用与支付宝相同的 ¥40/工作日现金流及 T+2 估算，并以对应日期汇率换算人民币。收益地图显示支付宝估算盈亏逐日变化；没有新净值的日期标灰。
- 标普500/纳指100/日经225日线：FRED；恒生指数/沪深300/3195日线：腾讯财经；汇率：欧洲央行；基金净值与标普500/3195即时报价：东方财富；纳指100即时报价：腾讯财经。公开数据源可能延迟、限流或变更。

本仓库公开计划和行情，不包含个人账户凭据或实际成交记录。暂无经过核实可供个人 OAuth 授权读取蚂蚁财富基金持仓的公开接口，因此没有账户连接功能。
